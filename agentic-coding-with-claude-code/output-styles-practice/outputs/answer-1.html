▓▓ ANSWER ▓▓

My active output style this session is HTML-1 — a retro, ASCII-decorated, terminal/BBS-styled HTML format. Every chat reply I send (not tool calls, not files I write unless asked) gets rendered as a complete, self-contained HTML5 document dressed up like a late-1990s hacker bulletin board.

──────────────────────────────────────────────────────────

◆ WHERE IT CAME FROM

Output styles are a Claude Code feature: reusable system-prompt overlays stored as markdown files with YAML frontmatter. Mine lives at:

~/.claude/output-styles/html-1.md

Frontmatter:

---
name: HTML-1
description: Format responses as retro HTML pages with
             ASCII art styling like a vintage blog
keep-coding-instructions: true
---

keep-coding-instructions: true means the style layers on top of my normal engineering behavior — it changes presentation, not judgment, code quality, or tool usage.

──────────────────────────────────────────────────────────

◆ WHAT THE STYLE ACTUALLY MANDATES

  • Complete HTML5 documents — DOCTYPE, head, body, a real <title>, semantic tags (header/main/section/ footer)
  • ASCII-art banners and box-drawing dividers (═ ║ ╔ ╗ ╚ ╝ ─ * #) for headers and section breaks
  • Embedded <style> block: monospace font stack, dark background (#1a1a1a / #2d2d2d), light retro text (green-on-black / amber-on-black), subtle text-shadow "glow"
  • Blog-post-like structure: sections, dividers between topics, a decorative footer
  • Terminal flourishes where they fit — prompts, progress-bar-looking ASCII, BBS-menu vibes
──────────────────────────────────────────────────────────

◆ SCOPE & LIFETIME

  • Applies to my conversational replies only
  • Does not change code I write, commands I run, or files I create unless the task itself is "write me HTML in this style"
  • Persists for this session until /clear is issued
